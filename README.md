# 이창현 | Software Developer

서비스의 문제를 구조화하고, **백엔드·데이터·AI 에이전트**를 연결해 실제로 동작하는 제품을 만듭니다.

[포트폴리오](https://lchserver.com) · [Agent Factory](https://github.com/KoreanLeeChangHyun/agent-factory) · [Day-log](https://github.com/KoreanLeeChangHyun/Day-log)

## 하는 일

- **제품과 백엔드** — 앱, 운영 어드민, 외부 시스템이 연결되는 서비스 흐름을 설계하고 구현합니다.
- **AI 에이전트** — 대화형 경험과 도구 연동을 제품 기능으로 연결합니다.
- **데이터와 자동화** — ETL, 데이터 통합, 반복 가능한 개발·배포 도구를 만듭니다.
- **게임 개발** — Godot으로 게임 시스템과 인터랙티브 프로토타입을 구현합니다.
